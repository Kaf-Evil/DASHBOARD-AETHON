3. El proceso de venta paso a paso

  • Identifica el candidato Usa las preguntas diagnóstico de cada producto. Si el dolor está presente, hay oportunidad. No trates de vender a quien no tiene el problema.
  • Agenda una llamada de diagnóstico Dile: "Te conecto con el equipo de Aethon para una llamada de 30 minutos gratuita." Usa el link de Calendly: calendly.com/fjavier-morc/30min — Francisco hace esa llamada, tú solo la agendas.
  • Aethon envía la propuesta Después de la llamada, Aethon prepara una propuesta personalizada. Tú recibes copia para hacer seguimiento con el cliente.
  • El cliente firma y paga Aethon gestiona el contrato y el cobro. Tú no tocas dinero — tu comisión se transfiere directo a tu cuenta el mismo día del pago del cliente.
  • Aethon implementa, tú cobras recurrente Aethon entrega el producto. Mientras el cliente sigue pagando, tú sigues recibiendo el 10% mensual — sin hacer nada adicional.
